# Lecture Note AI 🎙️

講義音声をアップロードすると、Gemini API が **3行要約 / 要点 / 文字起こし全文** を生成するシンプルな静的サイトです。

公開URL: https://yossyue.github.io/gemini/

## 使い方

1. [Google AI Studio](https://aistudio.google.com/apikey) で Gemini API キーを取得する
2. サイトを開き、「設定」にキーを貼り付けて「APIキーを保存」（疎通確認が走ります）
3. 「音声入力」で講義名（任意）と音声ファイルを選び、「ノートを生成する」
4. 生成された各セクションは「コピー」ボタンでクリップボードにコピーできます

## 仕様・制限

- **モデル**: `gemini-2.5-flash`
- **音声ファイル**
  - 約14MB以下: リクエストに直接埋め込んで送信
  - 約14MB超: Gemini File API にアップロードしてから解析（ブラウザのCORS制限で失敗する場合があります。その際はファイルを分割してください）
- **出力上限**: 1回あたり最大 65,536 トークン。長時間の講義は文字起こしが途中で切れることがあり、その場合は警告が表示されます。**30〜40分ごとに分割**して処理するのが安定します。
- 対応音声形式の目安: mp3 / wav / m4a / aac / ogg / flac / opus / webm

## セキュリティ上の注意

- 完全なクライアントサイド構成です。API キーはブラウザの `localStorage` に平文で保存され、リクエストのクエリパラメータ（`?key=...`）として送信されます。
- **共有PCでは使用しないでください。** キーは自分専用のものを使い、不要になったらブラウザのサイトデータを削除してください。
- 想定外の課金を避けるため、Google Cloud 側で API キーに使用量上限やリファラ制限を設定することを推奨します。

## 開発

ビルド不要。`index.html` / `main.js` / `style.css` の3ファイルのみ。
`main` ブランチへ push すると GitHub Pages に自動反映されます（約1分）。

ローカル確認:

```bash
python -m http.server 8000
# http://localhost:8000 を開く
```
